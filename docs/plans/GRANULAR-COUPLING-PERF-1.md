## 1. Контекст: где именно горит

Замер (`bench_regression_diagnosis`, уже с `physics_interpolation=false`):

| фаза | FPS сейчас | FPS с выключенным GranularBody (потолок) |
|---|---|---|
| parked | ~141 | ~128 |
| unparked idle | ~79 | **~133** |
| driving | ~72 | **~122** |

Корень (не «гранулярка сломалась»):

1. `26cd9ec` — `ProjectedAssemblyBody._ready()` вешает `GranularBody` на
   **каждое** projected RigidBody.
2. `b8e8b2d` (WHEEL-BODY-V1) — каждое колесо стало отдельным телом,
   демо-ровер = **~13 тел**. Auto-attach не обновляли → ×13 сэмплеров.
3. Под ровером в бенче стабильно **3 региона / ~1600 active cells**, поэтому
   заявленный дешёвый путь «нет региона → пара bounds-checks» почти не
   срабатывает.
4. Каждый сэмпл: `Dictionary(world.call(&"dust_at", point))` →
   перебор регионов → `dust_column_at` → `affine_inverse()` →
   **4** × `_column_at` → полный проход по `field.size.y`.

Порядок величины: `13 тел × 27 сэмплов × 4 колонки × ~96 ячеек × 30 Hz`
≈ **4 млн** `mass_at` в секунду + ~10 тыс. Dictionary/с.

Файлы, которые предстоит менять:

- `scripts/simulation/runtime/granular_voxel_region.gd`
  (`dust_column_at`, `_column_at`, мутации поля)
- `scripts/granular_voxel_world.gd` (`dust_at`, новый батч-метод)
- `scripts/simulation/runtime/granular_body.gd` (`_resample`, стаггер)
- `scripts/simulation/runtime/granular_voxel_field.gd` (точки мутации ячеек)

### Этап 1 — кэш колонок в регионе (главный выигрыш)

**Что:** `_column_at(cell_x, cell_z)` сейчас каждый раз идёт по всему Y.
Сделать на регион кэш 2D-массива результатов.

**Как:**

1. В `GranularVoxelRegion` добавить:
   - `var _column_cache: PackedVector2Array` размера `field.size.x * field.size.z`
     (индекс `cell_z * field.size.x + cell_x`);
   - `var _column_dirty: PackedByteArray` того же размера, инициализировать
     единицами (всё грязное);
   - хелпер `_column_index(cell_x, cell_z) -> int`.
2. `_column_at` превратить в: если `_column_dirty[i] == 0` — вернуть
   `_column_cache[i]`; иначе посчитать старым кодом, положить в кэш,
   снять флаг. **Тело старого расчёта не менять**, только обернуть.
3. Найти **все** места, где меняется масса ячейки. Искать по
   `granular_voxel_region.gd` и `granular_voxel_field.gd`:
   `set_mass`, `mass_at` с записью, `add_mass`, `deposit`, `dig_at`,
   `push_at`, `settle`, `step`, `sweep`, `sinter`, `prime_rock`,
   `restore`/`load`. Для каждого — помечать грязной колонку `(x, z)`.
   Если проще и надёжнее: пометить грязной колонку в **одной** низкоуровневой
   точке записи массы (лучший вариант — там, где поле реально пишет ячейку),
   тогда все верхние пути закрываются автоматически. **Предпочти этот путь.**
4. Массовые операции (settle-свип по всему полю, `restore_field_snapshot`,
   ресайз) — можно грубо: `_column_dirty.fill(1)`.
5. `field.size` / `cell_size` меняются → пересоздать кэш.

**Инвариант:** значение, которое возвращает `_column_at`, обязано совпадать
с прежним бит-в-бит. Кэш — только мемоизация, никакой новой математики.

**Проверка:** 2.2 полностью (особенно `field_parity`, `persist`, `sinter`,
`patch`), затем 2.1.

**Ожидание:** основной прирост здесь. `unparked`/`driving` должны заметно
подняться от baseline.

**Если `field_parity` красный** — почти наверняка пропущена точка
инвалидации. Не «подкручивай» тест: найди запись массы, которая не помечает
колонку грязной.

### Этап 2 — убрать аллокации и динамический вызов

**Что:** `GranularBody._resample` делает
`Dictionary(world.call(&"dust_at", point))` — Dictionary + вызов по имени на
каждый сэмпл каждого тела каждый сэмпл-тик.

**Как:**

1. В `GranularVoxelWorld` добавить типизированный метод без Dictionary,
   например `dust_probe(world_point: Vector3) -> Vector4` где
   `x,y,z` = surface (world), `w` = `depth_m`; `depth_m <= 0.0` = «нет
   материала». Точный формат выбери сам, но **без Dictionary и без `call()`**.
2. В `GranularVoxelRegion` — парный метод рядом с `dust_column_at`,
   возвращающий то же самое без Dictionary. Старый `dust_column_at`
   **оставить** (его зовут другие места) и реализовать через новый.
3. `GranularBody._resample` перевести на новый метод, `_body`-путь
   типизировать (без `world.call`).

**Инвариант:** `dust_column_at` продолжает возвращать тот же Dictionary с
теми же ключами `depth_m` / `surface` для остальных вызывающих
(персонаж и т.п.). Найди их grep'ом и не сломай.

**Проверка:** 2.2 + 2.1.

### Этап 3 — батч на тело

**Что:** сейчас 27 сэмплов = 27 × (перебор регионов + `world_transform()` +
`affine_inverse()`).

**Как:**

1. `GranularVoxelWorld.dust_probe_many(points: PackedVector3Array, out: PackedVector4Array) -> void`
   (или возврат нового массива): регион ищется один раз для группы, если все
   точки в его `covers`; `world_transform()` и `affine_inverse()` считаются
   один раз на регион.
2. `GranularBody._resample` собирает мировые точки сэмплов в
   переиспользуемый буфер-член (не создавать массив каждый тик!) и делает
   один батч-вызов, дальше крутит тот же цикл по результатам.
3. Точки, попавшие в разные регионы, обработать корректно — не «первый
   регион для всех». Простой честный вариант: сгруппировать по региону.

**Инвариант:** результат на каждую точку — тот же, что дал бы одиночный
вызов, включая порядок выбора региона (в текущем коде — с конца списка
`_regions`, последний покрывающий выигрывает; сохранить эту семантику).

**Проверка:** 2.2 + 2.1.

### Этап 4 — early-out по AABB

**Что:** тело, стоящее на коре вдали от кучи, всё равно платит 27 сэмплов.

**Как:**

1. У региона уже есть bbox тронутых ячеек (добавлен в `a3a3da6`, PERF-H13) —
   найди его и переиспользуй; если он только для sinter, сделай публичный
   геттер мирового AABB заполненной части.
2. В `GranularVoxelWorld` — `has_material_near(aabb: AABB) -> bool`
   (или `bool` по центру+радиусу).
3. В `GranularBody._resample`: посчитать мировой AABB тела (из `_samples` /
   `_local_bounds()` + текущий трансформ), спросить мир, и если пересечения
   нет — `_submerged = 0.0`, `_wet_points.clear()`, выход **до** сэмплов.

**Инвариант:** тест должен быть **консервативным** — AABB с запасом (margin
хотя бы одна `cell_size`). Ложноотрицательный = машина перестала чувствовать
кучу, это баг качества, а не оптимизация.

**Проверка:** 2.2 + 2.1. Плюс глазами: в бенче под ровером регионы ЕСТЬ,
так что early-out не должен «улучшить» driving до потолка — если улучшил
сильно, ты, скорее всего, режешь реальные сэмплы. Проверь.

### Этап 5 — стаггер тел по тикам

**Что:** все ~13 тел сэмплятся в один и тот же тик → пиковый кадр.

**Как:**

1. Каждому `GranularBody` дать стабильный фазовый сдвиг (например от
   `get_instance_id()` или счётчик при аттаче) и распределить момент
   `_resample` внутри интервала `1 / sample_hz`.
2. **Частота на тело остаётся `sample_hz`** — меняется только фаза.
   Никакого «реже».
3. То же для `_shove` / `press_hz`, если пик от него.

**Инвариант:** каждое тело по-прежнему сэмплится 30 раз в секунду.

**Проверка:** 2.2 + 2.1. Смотреть не только `fps_now`, но и
`native_gap_max_ms` — пик должен упасть.

### Этап 6 — адаптивные сэмплы (только если этапов 1–5 не хватило)

**Что:** 27 сэмплов нужны на границе (форма отпечатка). Полностью сухое или
полностью погружённое тело можно определить дешевле.

**Как:** одна проба в центре + проверка по AABB: если тело целиком выше
поверхности — 0 сэмплов; целиком ниже — можно считать `_submerged = 1.0`
и взять центроид без 27 проб. **Граница — всегда полные 27.**

**Риск:** это единственный этап, который может изменить поведение. Делать
только при необходимости и с явным замером «отпечаток тот же».
