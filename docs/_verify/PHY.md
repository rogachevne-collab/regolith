## R8 evidence (Godot Jolt, встроенный в 4.8, не legacy extension)

- Офиц. дока [Using Jolt Physics](https://docs.godotengine.org/en/latest/tutorials/physics/using_jolt_physics.html):
  freeze_mode=KINEMATIC двигается только назначением позиции/сетевого pose, без joint-force
  интеграции — ожидаемо для PHY-09 (реплика).
- [RigidBody3D](https://docs.godotengine.org/en/stable/classes/class_rigidbody3d.html):
  `freeze=true` → «Gravity and forces are not applied anymore» — подтверждает, что freeze
  само по себе безопасно останавливает интеграцию сил на теле (релевантно PHY-01/02/04/13).
- [godotengine/godot#89859](https://github.com/godotengine/godot/issues/89859): смешанный
  freeze на двух телах одного Joint3D может застопорить **не**-замороженное тело «in certain
  configurations» — подтверждает, что PHY-01/02/13 не гипотетические, а класс известных
  проблем в текущем движке; конкретный исход для WHEEL-BODY-V1 constraint-геометрии проекта
  не выводится из доки/issue напрямую → PHY-13 требует playtest.
- [godotengine/godot#115051](https://github.com/godotengine/godot/issues/115051): joint,
  подключённый к kinematic-телу, двигаемому скриптом/сетью, может давать jitter/oscillation —
  релевантно для потенциального будущего добавления wheel joints на replica (PHY-09 сейчас
  избегает этого, не создавая constraints на клиенте вовсе).
